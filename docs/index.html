Features

Built for fluid Japanese reading and sentence mining on mobile

Works Over Any App

Horizontal and vertical text, portrait and landscape. The popup positions itself dynamically where space allows and never covers the word you are looking up.

Full Yomitan Dictionaries

Rich entries with examples, pitch accent graphs, frequency lists, kanji breakdowns, and grammatical inflections with clear explanations.

Screen Text & OCR

Recognizes screen text using cloud recognition with an instant on-device draft, or extracts text directly from apps via accessibility for 100% offline accuracy.

1-Tap Anki Cards

Seamless export through AnkiDroid: customizable note types, field templates, duplicate detection, native pronunciation audio, and automatic screenshot attachments.

Audio & Pronunciation

Native pronunciation audio from the same community sources as Yomitan, or phone text-to-speech fallback.

Private & Open Source

No user accounts, no analytics, and no advertisements. Lookups and on-device recognition work completely offline.

How to Install

Get started with Screenlate on your Android phone

  1. Download the APK: Get the latest version from GitHub Releases. arm64-v8a fits modern smartphones. (You can also track updates with Obtainium).
  2. Enable Accessibility Service: Open Screenlate and grant the accessibility service permission to allow the floating bubble and screen scanning.
  3. Ready to read: JMdict, KANJIDIC, frequency lists, and pitch accents are bundled. Additional dictionaries (like Jitendex) can be downloaded in one tap from the in-app catalog.
